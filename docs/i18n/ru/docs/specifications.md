# Характеристики и результаты испытаний

Измерения выполнены на прототипах Robonine в августе и сентябре 2026. Значения с пометкой *расчётное* получены из модели URDF и документации сервоприводов, а не измерены.

<a id="current-and-temperature-follower"></a>
## Ток и температура ведомой руки

Измерено при нагрузке 300 g на повторяющейся траектории, температуре окружающей среды 30 °C, с шестью сервоприводами STS3250.

| | |
|---|---|
| Средний ток | 1.26 A |
| Пиковый ток | 3.28 A |
| Максимальная температура сервопривода | 46 °C |

<a id="absolute-accuracy"></a>
## Абсолютная точность

Настройка продолжается. При штатных параметрах PID сервоприводов кончик полностью вытянутой руки проседал примерно на 50 mm под её собственным весом. После настройки PID прогиб уменьшился примерно до 5 mm. Отдельный профиль точности разрабатывается.
