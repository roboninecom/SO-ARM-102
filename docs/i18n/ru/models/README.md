<a id="3d-models"></a>
# 3D-модели

| Папка | Содержание |
|---|---|
| `3mf/` | Проекты Bambu Studio с сохранёнными раскладками, ориентацией и поддержками |
| `stl/` | Сетки для печати, бинарный STL, миллиметры |
| `step/` | Детали и сборки CAD |

Папки `stl/` и `step/` имеют одинаковую структуру:

- `common/` — Общие детали, включая корпуса контроллеров.
- `follower/` — Параллельный захват и крепление камеры.
- `leader/` — Рукоятка, курок и узел вращения запястья.

<a id="3mf-slicer-projects"></a>
## Проекты слайсера 3MF

| Проект | Состав | Сохранённый профиль пластика |
|---|---|---|
| [SO102_leader.3mf](../../../../models/3mf/SO102_leader.3mf) | Одна ведущая рука: звенья, рукоятка, курок, узел вращения запястья и корпус платы | Bambu PETG-CF |
| [SO102_follower_arms.3mf](../../../../models/3mf/SO102_follower_arms.3mf) | Детали одной ведомой руки | Fiberon PET-CF17 |
| [SO102_follower_gripper_base.3mf](../../../../models/3mf/SO102_follower_gripper_base.3mf) | Захват и основание ведомой руки; Общие детали, включая корпуса контроллеров | Bambu PETG-CF |

Открывайте файлы как проекты в **Bambu Studio**, чтобы сохранить настройки. Во всех трёх используется профиль **Bambu Lab A1, сопло 0.4 mm**и по одному столу**256 × 256 mm**. Перед нарезкой выберите свой принтер, сопло и пластик. Для меньшего стола распределите детали по дополнительным столам, сохранив ориентацию и поддержки.

Для одной ведущей и одной ведомой руки напечатайте все три проекта по одному разу. Каждый проект руки уже включает общие детали для одной руки: отдельный общий набор печатать не нужно.

Сохранённые настройки и раскладки: [docs/printing.md](../docs/printing.md#3mf-slicer-projects).

Номера деталей, количество и параметры печати: [docs/printing.md](../docs/printing.md).

Напечатайте [образец для проверки направляющих](../../../../models/stl/test/Gripper%20test%20plate%20star%20holes%206.0-6.3.STL) тем же материалом и с теми же настройками, что и зажимы. Проверяйте отверстия 6.0–6.3 мм от большего к меньшему: нужна плавная посадка с минимальным люфтом. В репозитории есть только зажимы D6.1; другой результат требует соответствующей версии зажима перед печатью. Образец — инструмент проверки, не деталь комплекта.
