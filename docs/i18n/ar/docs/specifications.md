<a id="absolute-accuracy"></a>
## الدقة المطلقة

لا يزال الضبط جاريًا. مع إعدادات PID الأصلية للسيرفو، هبط الطرف نحو 50 mm تحت وزن الذراع نفسها عند مدّها بالكامل. خفّض ضبط PID هذا الهبوط إلى نحو 5 mm. يجري إعداد ملف مخصص لتقييم الدقة.
